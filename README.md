# agent-ophtho-weekly

专门用于 **眼科 × Agent 文献周报** 与备选 **AI 技术周报** 的推送仓库。

## 目录

- `reports/`：每周 Markdown 报告（按日期命名）
- `templates/`：报告模板

## 周报规则

1. 每周一检索过去 7 天「眼科 × Agent / Agentic / multi-agent」文献。
2. 有直接相关文献 → 写眼科 Agent 周报，并邮件发送。
3. 几乎没有 → 改写 AI 最新技术周报，并邮件发送。
4. 每篇文献必须包含：**题目、摘要、单篇小结**；全文必须有 **本周总结**。

## 命名

`reports/YYYY-MM-DD_眼科Agent周报.md` 或 `reports/YYYY-MM-DD_AI技术周报.md`
