## 条目列表

### 1. OpenAI Codex Multi-Agents v2：Sol/Terra 可把任务委派给 Luna

- **日期 / 来源**：约 2026-08-15；Runtime Wire / CryptoBriefing 等报道
- **链接**：https://runtimewire.com/article/openai-lets-gpt-5-6-sol-delegate-grunt-work-to-cheaper-luna-agents
- **相关度**：方法可迁移（Agent 编排范式）
- **摘要**：OpenAI 在 Codex 的 Multi Agents v2 中打通跨模型委派：高能力模型（如 GPT-5.6 Sol / Terra）可继续做编排与规划，同时把边界清晰的子任务交给更快更便宜的 Luna。此前 Luna 卡在 Multi-Agent v1，导致 Sol/Terra 无法正常 spawn；v2 修复后，模型选择变成「编排决策」而非整场会话固定一个模型。默认仍可「父子同模型」以保质量，但新模式更适合控延迟与 token 预算。
- **单篇小结**：眼科多工具 Agent（质控→分割→分类→报告）很适合「强模型规划 + 弱模型跑工具/批处理」；部署时优先设计可路由的子 Agent 接口，而不是一律上旗舰模型。

### 2. Google 发布 Gemini 3.7 Flash：面向 coding / agents 的工作马模型

- **日期 / 来源**：2026-08-13；Google AI Blog
- **链接**：https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/
- **相关度**：方法可迁移（Agent 骨干选型）
- **摘要**：Gemini 3.7 Flash 定位为「最聪明的工作马」，强调软件工程、知识工作与 Web 开发工作流，并明确面向 agent 场景；距 3.6 Flash 仅约三周。引入价约 **$0.75 / 1M input**、**$3.75 / 1M output**（约为 3.6 的一半量级口径，以官网为准）。同步进入 Antigravity、AI Studio、Enterprise Agent Platform，并用于 Gemini Spark 个人 Agent。
- **单篇小结**：临床 Agent 的高频 tool-calling / 反思循环成本敏感；Flash 级模型更适合作为「调度核」或二级反思，旗舰模型留给疑难病例与最终报告。

### 3. Frontier LLM 格局（2026 年 8 月中）：没有单一全能冠军

- **日期 / 来源**：约 2026-08 中；CASRAI 综述
- **链接**：https://casrai.org/news/frontier-llm-landscape-august-2026
- **相关度**：背景（选型与治理）
- **摘要**：综述指出 Claude Opus 5（约 7/24）、Claude Fable 5、GPT-5.6、Grok 4.6（约 8/12）、开源可自托管的 Kimi K3 等各擅胜场。行业从「固定大中小三档」转向 **同一模型可配置 reasoning effort**；采购问题从「选哪个模型」变成「哪个模型 × 哪个 effort × 哪类任务」。Gemini 3.7 Flash 则代表速度–成本一端。
- **单篇小结**：眼科 Agent 评测应报告「骨干 + effort/温度 + 工具集」组合，而不是只比模型名字；院内部署还需兼顾数据驻留与可审计性。
