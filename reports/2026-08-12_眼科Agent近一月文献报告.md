### 2. Guideline-as-Oracle: Zero-Annotation Training of an Ophthalmic Telephone Triage Agent

| 字段 | 内容 |
|------|------|
| **状态** | arXiv 预印本（2026-08-05 提交） |
| **链接** | https://arxiv.org/abs/2608.04772 · HTML: https://arxiv.org/html/2608.04772v1 |
| **作者** | Chenyu Wang, Yi Liu, Baoqing Li, Min Tu, Diping Song（通讯） |
| **模态 / 任务** | **无影像**；眼科电话分诊（Emergent / Urgent / Routine）多轮对话 Agent |
| **Agent 形态** | 多轮问询 Nurse-role Agent；用 **Guideline-as-Oracle (GAO)** 将 AAO 指导编译为 **70 行规则表**，作为 3000 条训练对话的唯一实例级监督 |
| **方法要点** | 系统化 8 种「规则→对话」构造策略；9B 骨干全参 SFT → **GAO-Triage**；强调评测是 **政策符合度** 而非临床金标准 |
| **主要结果** | 相对 base：与 201 例操作参考一致率 **61.7% → 74.1%**（McNemar p=0.0046）；急症召回 **9.5% → 69.0%**；7 个通用系统均未能在两指标上同时压过它；打乱标签–对话对应会塌成恒常 Routine |
| **启示** | 对「有指南、缺对话标注」的眼科场景（分诊、随访、健康教育）极有参考价值；部署前需独立多医师标注与交互外部基准 |
