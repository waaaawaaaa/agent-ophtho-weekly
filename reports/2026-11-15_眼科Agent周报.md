### 1. RetinaGuard: Risk-Controlled Agentic Triage for Multi-Disease Retinal Screening

- **日期 / 来源**：arXiv `2611.10689v1`，submitted **2026-11-07**。FAST National University of Computer and Emerging Sciences（Sohaib Sulman / Muhammad Atif Saeed / Akhtar Jamil）+ Istinye University（Alaa Ali Hameed）+ Saarland University / DFKI（Roland Aydin）
- **链接**：https://arxiv.org/abs/2611.10689 · https://arxiv.org/pdf/2611.10689 · 本窗口未见与作者匹配的公开代码仓
- **相关度**：**直接相关（本周主条目）**——眼底多病种筛查上的风险受控 Agentic 分诊；**不是**工具调用 LLM，报告槽是模板
- **摘要**：筛查项目要决定哪张自动读片可以不经人工。RetinaGuard 把质量、诊断、不确定度、核对、解释、决策、报告写成共享病例状态的 agent 图。质量 Agent 用 9 个摄影特征的马氏距离，超过验证集 99 分位先转诊；诊断 Agent 微调 RETFound ViT-L/16；不确定度 Agent 做 20 次 Monte Carlo；核对 Agent 是独立 ConvNeXt-B，从不替换主预测；解释 Agent 算 RETFound attention rollout 与核对器 Grad-CAM。失败预测器估计「不安全」概率——筛查标签错或漏掉任一存在的病种；假阳性不算不安全。核对与解释只在期望信息价值超过实测时延时才调用。接受阈值用 conformal risk control 在 384 张校准集上锁定。数据：RFMiD 官方划分（训练 1536 / 校准 384 / 验证 640 / 测试 640，25 个标签），ODIR-5K 只做外验，IDRiD 81 张只验解释。测试集 35.8%（229/640）的自动决策不安全。弱 RETFound（macro-AUROC 0.896）上，核对器分歧显著（ΔAUROC 0.058），20% 预算抓住 119/280 对最低置信度 88，α=5% 接受 37.0% 对 10.3%。强 RETFound（0.925，筛查 AUROC 0.974）上核对器几乎不加分（Δ 0.004），20% 预算 82 vs 68，Holm 后对不确定度基线不显著。两端覆盖率约 37.7%，VoI 门分别调用核对器 24.8% / 7.7% 的病例、从不调用解释 Agent，计算约少 30%。质量门把严重模糊等腐蚀下的最差不安全率从 60.2%→7.7%（弱）和 53.1%→28.0%（强）。ODIR-5K 不重训：筛查 AUROC 0.663，策略转诊 87.4%，实现不安全率 6.8% 仍超 5% 目标。IDRiD 上 ConvNeXt Grad-CAM pointing 0.864，RETFound attention rollout **0.123**（低于随机图）。
- **单篇小结**：这是对上窗口 *JAMIA*「能打的模型上再加 reviewer 只加倍 token」的眼底版，也是对黄斑裂孔工作流「RETFound 锁诊断」的分诊版。可搬的不是 0.925，而是三张表：**主模型不确定度已经解释了多少错误**（强模型上核对器 ΔAUROC 跨零）、**接受阈值必须单独校准**（α=5% 覆盖约 37%，不是「AUROC 好看就能全自动」）、**保证不随人群走**（ODIR 关键词标签上保证掉了）。接到糖网 / 青光眼社区筛查 Agent 时，应禁止把「再加一个核对 VLM」写成已经更安全；必须对照最低置信度 / 校准不确定度，并单独报质量门。不要把「Agentic」写成已经会调 GPT——报告 Agent 明确「对动作没有权限」。预印本未经同行评议；作者单位是计算机系，测试集 n=640，外集标签噪声大。

### 2. Auto-GlaKG、HalluciGuard-Eye 与青光眼 MCQ：可解释和防幻觉，仍不是工具槽

- **日期 / 来源**：arXiv `2611.11258` **2026-11-08** / *Front Endocrinol* 电子出版 10/20、本窗口索引（PMID 42978596）/ *J Glaucoma* **2026-11-02**（PMID 42970466）
- **链接**：https://arxiv.org/abs/2611.11258 · https://doi.org/10.3389/fendo.2026.1976190 · https://doi.org/10.1097/ijg.0000000000002804
- **相关度**：眼科相邻（规则 KG / KG-RAG / 选择题；均**不是**诊疗 Agent）
- **摘要**：**Auto-GlaKG**：ResNet50 预测杯盘比和 6 个形态征，再经固定临床先验规则聚合成青光眼分。689 张眼底、分组五折，pooled AUC **0.951**（灵敏度 0.970、特异度 0.779），与匹配图像分类器同为 0.951；规则层每张图加 0.2 ms。把预测 CDR 换成标注 CDR，折均 AUC 从 0.953 到 **0.995**——瓶颈是 CDR 估计，不是规则。**HalluciGuard-Eye**：4.7 万实体 / 15.6 万关系的眼科临床知识图谱 + 视觉语义对齐 + 事实接地，分层事实分打解剖 / 病理 / 建议。相对 SOTA 医学 MLLM 幻觉率降 **42.2%**，EyePACS 实体事实准确率 91.6%；糖网分级灵敏度 89.6%、特异度 92.1%（相对 MedRAG +2.4 / +2.7 个百分点）。**青光眼 MCQ**：DeepSeek-V3.2 / GPT-5.2 / Gemini 3 Pro / Claude Opus 4.5 做 129 道 AAO ONE + 32 道 BCSC 纯文本题。ONE 准确率 69.0% / **93.0%** / 92.2% / **96.1%**；BCSC 65.6% / **93.8%** / 84.4% / 87.5%。DeepSeek 显著落后。38/161 题被事后标成「直接有害错答」候选，实际 HW2 事件 4 次，模型间无显著差。

- **摘要**：青光眼 AI 常把少数公开集当「独立外验」。作者在 2026 年 7 月审计同一实验室放出的 Harvard-GDP（1,000 眼）、Harvard-GF（3,300 眼）和 Harvard-FairVision（10,000 眼）。视野 + 人口学指纹把 GF 与 FairVision 配上 1,302 眼（随机期望 1.9）。直接比图：1,031 对（79.2%；95% CI 76.9–81.4%）是同一份 3D OCT（余弦相似度 ≥0.9999，88% 体素完全相等），至少占 GF 的 **31%**。FairVision 三个划分里重复比例 78.5–80.8%。GDP 与 GF 另有 22 眼 52 个总偏差点 + MD 全等，全在 GF 验证划分；GDP 不发 OCT，证据较弱。文件没有患者标识，发布说明也没披露重叠。

### 4. Rotterdam AIROGS 外验、视网膜脱离 AI meta、基础模型适配与 ROP-MMNet

- **日期 / 来源**：*Ophthalmology* **2026-11-02**（PMID 42971439）/ *Graefes* **2026-11-14**（PMID 43033233）/ *Acta Ophthalmol* **2026-11-14**（PMID 43031527）/ *Artif Intell Med* **2026-11-10**（PMID 43025378）
- **链接**：https://doi.org/10.1016/j.ophtha.2026.10.030 · https://doi.org/10.1007/s00417-026-07618-1 · https://doi.org/10.1111/aos.70276 · https://doi.org/10.1016/j.artmed.2026.103563
- **相关度**：眼科筛查外验 / 诊断 meta / 基础模型实务 / 多实例融合（都**不是** Agent）
- **摘要**：**Rotterdam Study**：把 AIROGS 冠军算法（101,442 张黄斑为中心眼底）接到 19,088 眼 / 9,837 人，视野性青光眼 201 眼（1.1%）。眼级 95% 特异度下灵敏度 **70.6%**（63.8–76.8），ROC-AUC **0.911**，PR-AUC 0.343；人级灵敏度 68.8%、AUC 0.909。每检出 1 例约转诊 **5.1** 人。真阳性视野损伤更重（MD −10.8 vs −5.8 dB）；有既往影像的真阳性里 33/61（54%）在转换前 4–7 年就被标出。视盘为中心的 pAUC 高于黄斑为中心（0.860 vs 0.802）。视盘显示不全是假阳性主因。**视网膜脱离 meta**（检索至 2026-04）：66 项综述、31 项 / 118,432 张图入定量合成。合并灵敏度 **0.93**（0.89–0.95）、特异度 **0.98**（0.96–0.99），SROC AUC 0.982，DOR 642；作者写明外验和真实世界验证仍薄、方法异质性限制转化。**基础模型适配**（*Acta Ophthalmol*）：不分类模型本身，而是问「有了预训练权重，临床侧该微调还是线性探针」——看标注量、病种稀有度、域匹配。**ROP-MMNet**：多视角眼底 + 临床定量指标的多实例框架，用视盘/黄斑解剖位置编码聚合，做筛查和观察/治疗分类。
- **单篇小结**：Rotterdam 是给 RetinaGuard 的人群侧对照——**AUC 0.91 在 1.1% 患病率下仍要转诊 5 人才能抓 1 例**，和 conformal 只敢自动签约 37% 是同一句话。视盘不全 → 假阳性，正好对应 RetinaGuard 的质量门。RD meta 的 0.93/0.98 不能写成已经可部署——作者自己把外验写成瓶颈。基础模型文提醒：院内适配清单先写「微调是否必要」，不要默认再训一遍。ROP-MMNet 是融合不是编排。

- **链接**：https://doi.org/10.1016/j.survophthal.2026.11.010 · https://doi.org/10.1016/j.xops.2026.101402 · https://doi.org/10.1016/j.preteyeres.2026.101539 · https://doi.org/10.1136/bmjhci-2026-102263
- **相关度**：眼科工作流 / 监管 / 数据标准 / oculomics（都**不是** Agent）
- **摘要**：**手术视频**：白内障 / 玻璃体视网膜的阶段、器械、技能评估有公开集，活体工作流获益仍是早期，患者终点几乎没有；小样本机器人研究只证明医生控制下可行，不是 AI 自主。作者给未验证的四维框架：技术有效、外鲁棒、人因工作流、临床安全获益。**EU MDR + AI Act**：多数眼科 AI 是 IIa/IIb/III，且常因「安全组件」再被 AI Act 标成高风险，两套合格评定要叠。**眼前节摄影**：裂隙灯彩照缺少采集/处理标准，限制 AI 可部署表型。**合成超广角**：生成模型把普通眼底扩成 UWF-like，内验 AUC 真实 UWF 0.911 / 生成 0.773 / 中央裁切 0.689；外验生成 0.707 vs 原生 CFP 0.609，用于 CKD 筛查。
- **单篇小结**：手术视频文把「识别准 ≠ 临床获益」写成清单，接到白内障 / 玻璃体机器人 Agent 时应按四维分栏，禁止用猪眼导航代替患者终点。MDR/AI Act 是院内采购卡，不是新系统。合成 UWF 是数据增强，不要写成已经可替代超广角相机。

### 7. A multi-guideline clinical agent for vascular surgery: architecture, implementation, and benchmark evaluation

- **日期 / 来源**：2026-11-03；*JAMIA*
- **链接**：https://doi.org/10.1093/jamia/ocag178 · https://pubmed.ncbi.nlm.nih.gov/42978152/
- **相关度**：**方法可迁移（本周正刊主对照）**——锁定指南语料的多指南路由 Agent，可对 GUIDE
- **摘要**：ESVS 14 套指南约 1,100 页，床旁无法交叉引用。系统在已验证的单指南 GraphRAG 上加 LLM 指南路由器、缺关键参数就拒检的 Context Gate、双通道检索，再用 GPT-5 按强制引用模板合成。55 个vignette × 2 名盲法 LLM 评委 × 3 次 = 330 条判定，血管外科医师仲裁全部被标旗的声明。系统不离开锁定语料，拒答全部超范围提问，指南路由召回 **98.4%**。Context Gate 对欠指定查询特异度 91.9%、灵敏度 78.6%；259 条引用均可在语料内核实。敏感筛查定义下 18.2% 条目被自动评委标「无支持声明」；两名血管外科仲裁后，**7.3%** 含临床实质性错误，无一被判为可致伤害。完整答案的临床可接受度未打分，留给前瞻专家评。
- **单篇小结**：这是给 GUIDE 的外检课——**锁定语料 + 强制引用仍会留下 7.3% 实质性错误**。复现白内障 IOL / 抗 VEGF 指南 Agent 时应同时报：路由召回、Context Gate 拒答率、以及医师仲裁后的实质性错误，而不是只报 LLM-as-judge。不是眼科。

### 8. TRACER、RadStructAgent、PancreaGuide 与 Mayo 心内科病程：胸片 / CT / 出院小结上的 Agent

- **日期 / 来源**：2026-11-06 / 11-06 / 11-09 / 11-06
- **链接**：https://doi.org/10.1007/s10278-026-02469-y（PMID 42995374）· https://doi.org/10.1007/s11548-026-03811-z（PMID 42993382）· https://doi.org/10.2196/101607（PMID 43002664）· https://doi.org/10.1161/circoutcomes.126.014472（PMID 42993583）
- **相关度**：方法可迁移（可检查的多 Agent、结构化改写、知识增强 CT Agent、EHR 工具调用病程；都不是眼科）
- **摘要**：**TRACER**：胸片多 Agent，带结构化发现、Grad-CAM、执行轨迹。2,000 张正位报告质量六项自动指标最优；60 名非放射科用户上，透明度支持把会诊准备质量从 2.13 提到 3.14（OR 6.76）。**RadStructAgent**：用小模型把自由文本胸片报告改成 SRRG 结构，GREEN 0.494→0.539；Qwen3-4B/8B 经编排–评判–改写后再涨。**PancreaGuide**（华西 444 例）：结构化提示 + RAG + 胰腺外科知识库。Gemini+ 可切除相关信息准确率 **87.4%**、灵敏度 95.9%。**Mayo 心内科**：Gemini 2.5 Pro + MCP 按需拉病历。50 次住院、5 名医师 250 次评分：医师稿被偏好 52.8% vs Agent 47.2%（OR 1.12，CI 跨 1）；总分 7.42 vs 7.27，差异不显著。
- **单篇小结**：四条分别对应眼科的四件事——OCT 报告要可点回轨迹（TRACER）；自由文本手术史要先结构化再给下游（RadStructAgent，接 Beyond Billing Codes）；抗 VEGF / 白内障围术期咨询要知识库而不是通才（PancreaGuide）；出院病程「看起来能打平」不等于可以无人签发（Mayo）。全部不是眼病终点。

### 9. Clinical-SAM、放射 Agent 安全层、AgentCT 与 FDA 工具目录：编排之前先问工具清不清

- **日期 / 来源**：*IEEE TMI* **2026-11-12**（PMID 43019264）/ arXiv **2026-11-08 / 11-08 / 11-06**
- **链接**：https://doi.org/10.1109/tmi.2026.3753143 · https://arxiv.org/abs/2611.11541 · https://arxiv.org/abs/2611.11503 · https://arxiv.org/abs/2611.09836
- **相关度**：方法可迁移（测试时适应、动作前校验、按退化路由、用已批工具拼报告）
- **摘要**：**Clinical-SAM**：冻结 SAM，强化学习自提示，部署期只用医师对 mask 的二元接受/拒绝；六套肿瘤分割（CT/PET）自称相对微调 / TTA / 在线学习 SOTA。**放射工作流安全**（`2611.11541`）：6 个工具调用 LLM、48 个合成场景，动作前加确定性规则 ± 本地 LLM 检查器，主终点是每回合至少一次高严重度违规。**AgentCT**：Qwen3-VL-4B 识别 CT 退化类型（准确率 95.7%）再路由到低剂量 / 稀疏角度 / 金属伪影专科修复。**FDA 工具目录**（`2611.09836`）：问「把已批放射 AI 当工具，编排器能不能写出完整报告」——现有清单按部位/模态拼起来仍盖不住。
- **单篇小结**：接到眼底/OCT 工具槽时抄三句——医师反馈可以是接受/拒绝不必是框（Clinical-SAM）；**每次工具调用前要有独立校验**（放射安全层）；工具目录先于编排器（FDA 文）。AgentCT 的「先认退化再路由」可直接对 RetinaGuard 质量门。都不是眼科。
