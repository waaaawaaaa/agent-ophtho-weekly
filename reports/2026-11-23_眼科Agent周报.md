### 1. Not All Evidence Is Admissible: Evidence Governance for Tool-Augmented Medical Agents（CIEG）

- **日期 / 来源**：arXiv `2611.22169v1`，submitted **2026-11-17**。中国科学院自动化研究所（Runxun Zhang / Jingwei Wei）+ 中国科学院大学（Jinqiao Wang）+ Massachusetts General Hospital（Onofrio Antonio Catalano）
- **链接**：https://arxiv.org/abs/2611.22169 · https://arxiv.org/pdf/2611.22169 · 本窗口未见与作者匹配的公开代码仓
- **相关度**：**直接相关（本周主条目）**——工具增强医疗 Agent，成像主任务含 **REFUGE2 眼底青光眼筛查**；框架通科，不是眼科专用编排器
- **摘要**：工具增强医疗 Agent 默认把工具返回值当证据。作者证明这个默认很贵：医学工具会静默失败，冻结推理核不能忽略已经进上下文的内容，于是许多原本答对的病例被翻错，称为证据劫持。$\mathcal{V}$-information 解释了为什么：可用信息只在预测族拥有「可选无知」时才非负；冻结 LLM 没有这个选项，错误工具输出可以对标签携带负的可用信息。现有做法要么在调用前决定调哪个工具（看不到内容），要么在答题上下文里做反思（劫持已经发生）。CIEG 把流程拆成获取–准入–作答：每条工具输出写成可核对的 card（轮廓叠在原图上、报告原文、逐字引用的段落）；独立 Checker 只读输入和 card 池，按保真度与一致性决定放行哪些；Solver 只根据被准入的 cards 作答，8 次采样多数票。全程冻结、不训练。Checker 与 Solver 都是 Qwen3-VL-8B。任务：（i）REFUGE2 验证集 400 张眼底，工具为 BiomedParse / MedSAM / SAM 的视盘–杯分割及垂直杯盘比；（ii）Kermany 儿科胸片去重后 431 张，工具为 ChEX / MAIRA-2 / CURE 报告 + RAD-DINO 相似病例；（iii）MedQA 1,273 / MedMCQA 4,183 / NEJM 655，BM25+MedCPT 检索段落。主结果（成像为平衡准确率）：青光眼 CIEG **0.730** vs 同骨干 ReAct 0.544 / MedAgents 0.650 / MDAgents 0.586 / MAM 0.627 / 无工具 0.636；胸片 **0.837**；MedQA **82.72%**。青光眼每例约 **25.3k** token、中位 **5.5 s**，约为 MDAgents 的六分之一 token、约 22× 更低时延。把三条分割 card 全放行，会把 178/400（44.5%）原本正确的病例翻错；按错误 card 数分层，admit-all 从 0.83 掉到 0.61（一条错）再掉到 0.5 以下，CIEG 与无工具的差距始终 ≤0.07。Checker 在青光眼两类上 AUROC **0.93 / 0.85**，正确 card 放行 87%/76%，错误 card 只放行 19%/22%。预算匹配随机准入显著低于 CIEG，说明涨分来自「选对了」而不是「看少了」。
- **单篇小结**：这是对上窗口 RetinaGuard「强 RETFound 上核对器几乎不加分」和 OphthaAgent「不要盲目信工具」的信息论版。可搬的不是 0.730，而是三张表：**错误分割进上下文会主动伤人**（44.5% 正确病例被翻）、**准入必须在答题上下文之外**（ReAct 在青光眼上比不调工具还差 0.092）、**对照要同时报全放行 / 全拒绝 / 预算匹配随机**。接到糖网 / 青光眼 / OCT 工具 Agent 时，应禁止把「再加一个分割器或 RETFound」写成已经更安全；必须先报劫持率和 Checker AUROC。不要把 CIEG 写成眼科专用系统——胸片和选择题权重相当，没有医师读片终点，REFUGE2 验证集不是前瞻筛查队列。预印本未经同行评议；未见代码。

### 2. RetiDual-Select 与 24 万张眼底不确定度基准：路由和 UQ 都还不是工具槽

- **日期 / 来源**：arXiv `2611.22117` **2026-11-17**（Kent：Zihao Han / Philippe De Wilde）/ arXiv `2611.23344` **2026-11-17**（Jebeli / Eslami / Zebardast / Sobrin / Elze）
- **链接**：https://arxiv.org/abs/2611.22117 · https://arxiv.org/abs/2611.23344
- **相关度**：眼科相邻（OCT 专家–通才路由 / 眼底 UQ 基准；均**不是**诊疗 Agent）
- **摘要**：**RetiDual-Select**：冻结 RETFound（专科）与 MedSigLIP 图像编码器（通才），校准后的 product-of-experts 作静态参考；小门控提出替代融合，验证集冻结的 harm guard 决定是否允许替换，另开一条分数做审阅。数据：清洗后 Kermany-4（训练 49,263 / 验证 4,990 / 测试 968）、OCT-C8（18,264 / 2,795 / 2,797）、OCTDL 2,064 张七分类。静态 PoE 在三个数据集的干净准确率上最高或并列最高。干净 2% 接受错误目标下，审阅策略接受 Kermany-4 的 **94.3%**（选择性准确率 99.89%）和 OCT-C8 的 **92.4%**（98.65%）。两支都对的比例 95.0% / 91.8%，恰好一支对的只有 4.4% / 6.2%。15 个预设合成退化里，自适应增益集中在严重对比度下降；百分位重标定基本消掉这个效应。事后验证集分析：harm guard 把最差条件 OCT-C8 损失从 1.39 降到 **0.36** 个百分点。作者写明合成扰动不能代替真实采集/扫描仪漂移。**UQ 基准**：>242,000 张眼底、32 个数据集，覆盖糖网 / AMD / 青光眼；六种代表 UQ × 三种 ViT，测区分、校准、选择性预测和 conformal 预测集覆盖。结论是没有普遍最优的模型或 UQ：提升某一病种/架构的可靠性，换病种就可能掉；计算更重的方法并不稳定优于简单置信度，领域基础模型和校准损失也不保证更可靠。conformal 在假设成立时可把边缘覆盖拉到名义水平。
- **单篇小结**：两条正好接在 CIEG 两侧——**RetiDual-Select 证明「自适应融合也会推翻正确决策」**，和证据劫持是同一句话，只是对象从分割 card 换成了 RETFound vs MedSigLIP；**UQ 基准证明不确定度本身也没有万能配方**，RetinaGuard 用的 conformal 接受阈值不能默认搬到另一个病种。都不是工具编排。接到 OCT 双模型路由时，应先报「恰好一支对」的比例（本条只有 4–6%），再谈门控。

### 3. Comparative evaluation of GPT 5.2 Pro and Gemini 3 Pro large multimodal models for retinal optical coherence tomography interpretation

- **日期 / 来源**：2026-11-16；*Graefe's Archive for Clinical and Experimental Ophthalmology*。Cleveland Clinic Cole Eye Institute（Bellanda / Shin / Sharma 等）
- **链接**：https://doi.org/10.1007/s00417-026-07604-7 · https://pubmed.ncbi.nlm.nih.gov/43037730/
- **相关度**：眼科相邻（通才 LMM 零样本读 OCT；**不是** Agent）
- **摘要**：担心患者已经能把 OCT 丢给消费级多模态模型。330 张公开视网膜 OCT B-scan，12 个诊断类（含正常和常见视网膜病），零样本对照 GPT 5.2 Pro 与 Gemini 3 Pro。分别打九个预定 OCT 特征检测，以及自由文本诊断。Gemini 特征检测宏观 F1 **0.558** vs GPT **0.472**；诊断准确率 **58.8%** vs **32.1%**。显眼异常好于细微结构。正常 OCT 常被标成有病，**GPT 一张正常图都没认对**。存在反复、模型特异的诊断偏差和幻觉诊断。作者写明：模型能抽出部分临床相关信息，但诊断可靠性有限，不宜进入无监督的患者侧工作流。
- **单篇小结**：位置正好接在条目 1 之后——**通才多模态直接读 OCT 仍然过不了门，更没有工具槽。** 接到「最新 GPT / Gemini 已经会看 OCT」的采购话术时，应要求：正常图特异度、特征级 F1、以及有没有独立影像工具。32% / 59% 不能写成可签发；本条也提醒：院内 Agent 若把原图直接塞给旗舰 LMM 当「第二意见」，先要报它对正常扫描的过诊。

### 5. MoViT-Eye、EviRed 一年预测与 RETFound 外验：分类和预后仍停在模型头

- **日期 / 来源**：*PLoS One* **2026-11-16**（PMID 43038238）/ Research Square **2026-11-18**（PPR1370418）/ **2026-11-20**（PPR1372871）
- **链接**：https://doi.org/10.1371/journal.pone.0360848 · https://doi.org/10.21203/rs.3.rs-11433556/v1 · https://doi.org/10.21203/rs.3.rs-11702966/v1
- **相关度**：眼科相邻（眼底多分类 / 糖网一年风险 / 基础模型外验；都**不是** Agent）
- **摘要**：**MoViT-Eye**：MobileNetV2 + Transformer，4,906 张清洗眼底、五分类（DR / 青光眼 / 翼状胬肉 / 视网膜脱离等）。准确率 **90.36%**，MCC 0.8643，Kappa 0.8640，特异度 97.29%；识别 DR 与视网膜脱离的 AUC **98.60%**。用 LIME / Grad-CAM++ / Saliency 标微动脉瘤和视盘。**EviRed**：法国 14 家医院前瞻队列，3,183 名糖尿病患者、8,520 次访视、16,509 条眼级观察。按设备分别集成超广角眼底（CLARUS500 / OPTOS）和 OCTA（CIRRUS5000 / PLEX Elite9000），患者级 65/35 划分，预测一年后的 DR 严重度、PDR 和中心凹 DME。下一次年访严重度：OPTOS 二次加权 Kappa **0.866**（0.842–0.878），CLARUS **0.852**（0.830–0.877）。新发 ci-DME：CIRRUS5000 AUC **0.826**（0.770–0.878）；新发 PDR：PLEX Elite 点估计 **0.877**（0.807–0.950）。晚融合不稳赢最强单设备。完整病例里，图像风险分最高四分位的 ci-DME 发生率为 **19.7–30.4%**。作者写明需要外验、校准和前瞻效用。**RETFound vs ImageNet**：APTOS 2019 训练，原样外验 Messidor-2 / IDRiD。内测 QWK EfficientNet-B3 **0.879**、RETFound **0.888**。预设分析里 RETFound 的内外掉分差相对 EfficientNet，Messidor-2 为 +0.020（CI 跨 0）、IDRiD +0.033（CI 跨 0）。Messidor-2 上转诊级灵敏度只有 **36–43%**（特异度 90–98%），EfficientNet 把 259/270 张轻度 DR 打成无 DR。
- **单篇小结**：三条分别钉三句话——**混合卷积–Transformer 解释得了，仍不会调工具**（MoViT-Eye）；**单次常规影像里有一年风险信息，但还不是工作流 Agent**（EviRed）；**视网膜基础模型不能默认写成外验更稳**（RETFound 条的 CI 跨 0，转诊灵敏度掉到 40% 上下）。接到筛查 Agent 的预后槽时，EviRed 可以当「要不要预测而不是只分级」的对照，但必须按设备分栏、禁止把晚融合写成已经更好。两条 Research Square 均未经同行评议。

### 6. An open agentic AI co-scientist for clinical and biomedical discovery（OpenScientist）

- **日期 / 来源**：2026-11-16；*Nature Medicine*
- **链接**：https://doi.org/10.1038/s41591-026-04808-6 · https://pubmed.ncbi.nlm.nih.gov/43039361/
- **相关度**：**方法可迁移（本周正刊主对照）**——开源、可断网的科研 Agent；**不是**眼科
- **摘要**：生物医学分析被数据和领域时间卡住。OpenScientist 针对科学家给定的问题做可核查、数据落地的分析。领域专家在五例案例中评估：量化阿尔茨海默病血液标志物表现、在隐藏评估队列上做血浆蛋白组生存模型、提出 tau 病理与溶酶体酸化的可重复机制、产生并在外队列验证多发性骨髓瘤假说（随机对照中信号减弱）、以及在盲法预先指定的蛋白组比较中与独立人工分析一致。作者写这些分析从「数月」压到「数分钟」。为敏感临床数据，系统可在完全气隙环境用开源模型推理。定位是协助文献调研、假说、执行分析和从复杂数据出洞见，而不是替代专家。
- **单篇小结**：这是给 GUIDE / 眼科科研车间的外检课——**正刊已经接受「开源 + 气隙 + 人在环」的科研 Agent，但终点是发现而不是签发。** 复现白内障 IOL / 抗 VEGF 指南或队列分析 Agent 时应同时报：能否断网、分析是否可复现、以及有没有与独立人工分析的盲法对照。不要把五例案例写成已经覆盖眼底/OCT。

### 7. 长期临床 Agent 的轨迹治理、医疗 Agent 伦理综述与皮肤科「共同执业」框架

- **日期 / 来源**：*JMIR* **2026-11-19**（PMID 43066768）/ *Health Care Sci* **2026-11-17**（PMID 43048115）/ *Cell Reports Medicine* **2026-11-17**（PMID 43044568）
- **链接**：https://doi.org/10.2196/110563 · https://doi.org/10.1002/hcs2.70111 · https://doi.org/10.1016/j.xcrm.2026.103171
- **相关度**：方法可迁移（轨迹可恢复性、伦理治理、专科 agentic 共同执业；都不是眼科终点）
- **摘要**：**轨迹治理**（华西 / Vanderbilt）：临床 AI 正从单次预测走向反复调工具、改状态的长期 Agent。单步说得通的动作可以拼成不安全轨迹。作者提出以可恢复性为中心的轨迹治理：recovery margin 是人类–AI 系统在可接受纠错路径耗尽前仍能改道的余地；reauthorization boundary 是必须收回或收窄授权、等待人类重判的条件。可逆性是动作属性，可恢复性是轨迹属性。操作层包括持续义务跟踪、独立监测、显式再授权、权限收缩、降级、独立升级和核实的人类接管。评价应含轨迹压力测试、中断接管和人群监测；纠错能力依赖及时监测和人类救援，因此也是公平性问题。**伦理综述**（清华）：2020-01 至 2025-06，1239 条记录筛到 58 条。八个非互斥主题，居前的是安全/幻觉、问责、偏倚、隐私。核心 agentic 证据表明多步执行、外部工具、持久记忆和多 Agent 协调会放大误差传播与责任分配风险。提出四组件治理框架，作者写明尚未前瞻验证。**皮肤科评论**：多模态基础模型给了感知基线，但深色皮肤 / 罕见病 / 真实世界图像仍不齐；下一步是临床主体性——推理核编排主动感知、专科工具和纵向记忆。尚无系统在皮肤科端到端验证。评价必须看完整临床回合和患者/系统结局，而不是回顾基准。
- **单篇小结**：三条分别对应眼科的三件事——抗 VEGF / 青光眼随访 Agent 要报的是**这条轨迹还能不能救**（JMIR），而不是这一针建议对不对；采购伦理清单要覆盖工具、记忆和多 Agent，而不是只写幻觉（清华）；*Cell Rep Med* 的皮肤科框架几乎是 EyeAgent 的专科翻译，但作者自己把「尚未端到端验证」写在标题页。全部不是眼病终点。

### 8. VERA：给通才 VLM 加视觉 harness 的 agentic 环，评测里没有眼底

- **日期 / 来源**：arXiv `2611.22815v2`，submitted **2026-11-17**，revised **2026-11-18**。NJIT / UGA / NYU（Wan / Jiang / Zhao 等）
- **链接**：https://arxiv.org/abs/2611.22815
- **相关度**：方法可迁移（交互式视觉工具 + 证据管理的 agentic 环；评测为脾/肾/肺结节等，**不是**眼科）
- **摘要**：通才 VLM 的视觉能力不一定能直接变成医学任务。VERA 提供医学视觉 harness：导航/放大/三平面/测量工具、无损证据记忆、覆盖用的 Evidence Map、发现可靠性的 Evidence Verifier，以及提交初答后按遗漏和可靠性再检查的 agentic 环。11 项任务、四种成像模态。Qwen3.8-27B 上全部任务提升，脾脏测量 63.3%→**98.3%**，肾脏搜索 57.5%→71.2%，肺结节检测 0.0%→28.2%。API 骨干更高：GPT-6.1 Sol 肺结节 10.8%→**69.2%**，Claude Opus 5.5 到 60.0%。与若干 Agent 基线比，Qwen 骨干在 10/11 任务上最好或并列最好。
- **单篇小结**：可搬到 OCT / 超广角的是「先查覆盖再改答案」，不是肺结节的 69%。接到眼底 Agent 时应禁止默认抄 CT 的 slice 巡航；眼底是 2D 彩照，缺的是病灶级工具和质量门，不是三平面。本窗口评测未出现 CFP/OCT，不翻转直接相关口径。

### 9. GPT-6.2 Astra / Sol 与 Gemini 4 Neon：本周是「中间价旗舰」和「更快的 6.2」

- **日期 / 来源**：OpenAI 模型发布说明 **2026-11-17**；Google 官方博文 **2026-11-18**
- **链接**：https://help.openai.com/en/articles/9624314-model-release-notes · https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/
- **相关度**：运行时（本周平台层增量；Fable 5.2 / Carbon 开放 / Hydrogen 不重复）
- **摘要**：**GPT-6.2 Astra / Sol**（11/17）：进 ChatGPT Work / Codex（Plus/Pro/Enterprise/Edu）和 API `gpt-6.2-astra` / `gpt-6.2-sol`，**不进普通 Chat**。两者接受文本+图像、输出文本。官方价 Astra **$8 / $40**（缓存输入 $0.40；较 GPT-6 Astra 降 20%），Sol 维持 GPT-6.1 Sol 的 **$2 / $10**（缓存 $0.10）。社区同步口径：Astra 在 Agents' Last Exam 的 xhigh 比 GPT-6 Astra max 高 5.2 分、每任务成本不到一半；Sol 在 FrontierCode 2.0 上接近 Astra、成本约五分之一。11/18 起也在 Amazon Bedrock。**Gemini 4 Neon**（11/18）：`gemini-4-neon`，夹在 Hydrogen 与 Carbon 之间，1M 窗，思考档 low/medium/high（默认）/xhigh，**$3 / $15**（缓存输入 $0.15）。官方表 AA Index xhigh **61**（第 3），Vals Index **70.9%**（第 2），Agent Arena Index **1336**（第 2），Terminal-Bench 4.1 **65.2%**，FrontierCode 2.0 默认 high **46.2%**，Agents' Last Exam v1.1 **75.8%**。Antigravity 里可作编排器调度 Hydrogen 子 Agent。Fairwind 网络安全权后续几天给可信防御者，与院内眼科无关。同窗口 Genie 4 进 Gemini API 是世界模型，不展开。
