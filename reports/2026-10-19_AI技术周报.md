### 2. Grounded ophthalmic AI beyond the electronic health record trap: a critical narrative review

- **日期 / 来源**：2026-10-13；*BMJ Health & Care Informatics*
- **链接**：https://doi.org/10.1136/bmjhci-2026-102293 · https://pubmed.ncbi.nlm.nih.gov/42869617/
- **相关度**：眼科治理 / 架构（以眼科 VLM 为案例，主张可审计的「发现–位置–变化」；不是 Agent）
- **摘要**：EHR 证明信息化可以数字化工作，同时加重文书、刚性和倦怠。AI 可能比 EHR 进得更深——起草摘要、读图、建议随访并影响决策。糖网筛查和病灶级深度学习在**定义好的任务**上已成功，但临床解释不是分类：一句「黄斑硬性渗出增加」需要定位中心凹/黄斑、分割病灶、纵向配准、定量变化，再忠实生成语言。未解决的信息学问题是**落地的临床解释**：把图像翻译成医师可检查的 finding–location–change 三元组。作者提出三层架构：全球标准化客观观察、本地政策/工作流适配、带安全门的医师编写 AI 操作。定制不应被卖成厂商私活，而应写进采购、审计和生命周期监管。三层架构是概念框架，不是前瞻验证实现。
- **单篇小结**：这是对上周耶路撒冷「算法先开口」和 OphthaAgent「工具可错」的信息学版——**评的不是模型会不会写报告，而是报告里的每一个变化能不能被指回图上的坐标。** 接到 AgentEYE / EyeGraph / FFA-SegGPT 时应同时暴露：病灶图、配准、以及句子是否被分割约束。不要把「三层架构」写成已经可部署。

### 3. Artificial intelligence-supported diabetic retinopathy screening in Tanzania: a randomised controlled trial

- **日期 / 来源**：2026-10-12；*The Lancet Global Health*。LSHTM + Kilimanjaro Christian Medical Centre。ISRCTN18317152
- **链接**：https://doi.org/10.1016/j.langlo.2026.104062 · https://pubmed.ncbi.nlm.nih.gov/42863478/ · https://www.thelancet.com/journals/langlo/article/PIIS2214-109X(26)00224-X/fulltext
- **相关度**：**眼科工作流（本周最重的眼科 RCT）**——现场 AI 结果 + 当面咨询 vs 延迟人阅 + 电话；终点是到诊，不是 AUROC
- **摘要**：非洲糖网筛查的主要缺口是转诊后不到诊。坦桑尼亚 Kilimanjaro / Arusha 24 家医院 NCD/糖尿病门诊，个体 1:1 随机。AI 组：拍照后软件出非需转诊 / 需转诊 / 不可分级，离开摄影室前当面咨询，需转诊或不可分级转中心眼科。对照组：数周后电话告知人阅结果。主要终点：英国认证阅片员判定的**真需转诊**者 8 周内到中心眼科。2023-03-08～2024-08-31，2,439 评估、2,378 入组（AI 1,192 / 对照 1,186）。真需转诊 904 人（437 / 467）。8 周到诊 **157/437（35.9%）vs 85/467（18.2%）**，绝对差 17.7 个百分点（95% CI 12.0–23.4；OR 2.52，1.86–3.42；*P*<0.0001）。AI 组 100% 现场拿到结果；对照组人阅均时 23.1 天，仅 69.4% 接通电话，其余短信。到诊者均时：AI **10.9 天** vs 对照 36.9 天。作者结论：现场路径有潜力改善非洲糖网筛查。
- **单篇小结**：上周利比里亚离线相机问「基层能不能跑」；本条问「跑完人会不会来」。可直接搬到筛查 Agent：**第一指标应是真阳性到诊，而不是灵敏度。** 干预捆了三件事（即时结果、当面咨询、不可分级也转诊），不能把 17.7 个百分点写成「模型更准」。35.9% 仍意味着六成真需转诊 8 周内没到——Agent 若只负责出图分级，必须另有到诊槽。这不是诊疗 Agent，不翻转周报类型。

- **相关度**：**方法可迁移（本周正刊主对照）**——内化推理 vs 外部化多 Agent，二者可叠加

- **摘要**：复杂医学推理要跨多步整合异质证据。LLM 现有两条路：内化推理，或外部化 Agent 脚手架（多模型协作拆题）。MedicalAgentsBench：从 8 个医学数据集经难度感知筛选和污染检查得到 862 道复杂临床题。评了 3 个内化推理模型（DeepSeek-R1、o1-mini、o3-mini）、7 个基座和 9 种外部化 Agent。两条路各自独立加分，而且**会叠加**：最高准确率是内化推理模型再套 Agent（o3-mini + MDAgents **35.1%**）。帕累托分析显示该组合主导成本–性能前沿；轻量优化便宜模型可作为资源受限入口。

### 9. Skill-guided agentic reasoning enables longitudinal synthesis of myeloma records at expert-level concordance

- **日期 / 来源**：2026-10-14；*npj Precision Oncology*
- **链接**：https://doi.org/10.1038/s41698-026-01733-2 · https://pubmed.ncbi.nlm.nih.gov/42875467/
- **相关度**：方法可迁移（长病历 + 索引技能库的 Agent；可对 nAMD/青光眼纵向合成）
- **摘要**：多发性骨髓瘤患者数年累积数百份文书，每次治疗决策都依赖全史合成。811 人 / 25 年，44,962 份文书、1,334,677 条化验。在 469 对专家裁决的患者–问题上，对照单次 RAG、迭代 RAG、迭代 RAG+同一技能库、全上下文。技能引导 Agent 超过迭代 RAG（75.7%）和全上下文（75.8%）的天花板，达到 **80.1%** 一致；最复杂任务 +11.2 个百分点，最长病历优势更大。把同一技能库给迭代 RAG，总分可到 79.0%、短病历打平；Agent 在最长十等分仍显著领先（+10.3 个百分点，*P*=0.017）。总错误率 12.2%。MIMIC-IV 有探索性外测。
- **单篇小结**：上周 LongCAF 证明随访要有记忆和升级门；本条证明**长记录不是「把窗口开到最大」**——技能库比全上下文更值钱，Agent 只在最长史上才拉开。接到 nAMD / 青光眼病历合成时应先建可索引的专科技能（再治疗规则、视野进展定义），再决定要不要多步 Agent。12% 错误率不能无人签发进肿瘤/抗 VEGF 计划。

### 10. A multi-agent large language model (LLM) platform for structured medical anamnesis in outpatient care

- **日期 / 来源**：电子出版 2026-09-30；本窗口 *Frontiers in Digital Health* 可见
- **链接**：https://doi.org/10.3389/fdgth.2026.1882397 · https://pubmed.ncbi.nlm.nih.gov/42877149/
- **相关度**：方法可迁移（框架约束的多 Agent 问诊；人在环。模拟 100 例，不是眼科）
- **摘要**：门诊时间不够做系统问诊。Symptio 把 SOCRATES、系统回顾和 SAMPLE 写成机器可解释约束，人在环。100 个模拟门诊：三框架全结构一致 87%；分框架 96% / 88% / 93%。微平均 precision / recall / F1 = 99.04% / 98.54% / 98.79%。无高严重度错误，但有 58 处字段级出入（含 28 处中等），作者要求全部输出医师复核。
- **单篇小结**：形态接近 GAO-Triage「必问变量写成约束」，不是自由聊天。眼科电话分诊若上 LLM，应先把 SOCRATES/红旗写成不可跳过的槽，再谈多 Agent。100 例模拟不能写成已经能替分诊护士。

### 11. AI safety is a system property, not a sum of individual defenses；以及卫生经济学 Agent 概念建模

- **日期 / 来源**：电子出版 2026-09-25 / 2026-10-12；*Patterns* / *PharmacoEconomics - Open*
- **链接**：https://doi.org/10.1016/j.patter.2026.101686（PMID 42890770）· https://doi.org/10.1007/s41669-026-00687-2（PMID 42864590）
- **相关度**：治理 / 方法（安全失败会互相放大；图谱 RAG + Agent 做卫生经济学概念模型，人在环）
- **摘要**：**系统安全**（*Patterns*）：越狱防御、幻觉、公平和自主控制常被分开修。作者在真实复合事故上论证失败会互动放大，并提出四类挑战；在 MedQA-USMLE 临床 vignette 上审计 GPT-5 与 Claude Sonnet 4.6——**一次越狱可同时影响多个安全维**，模式随模型和攻击而变。设计原则三条；把 Agent 安全与机制可解释列为紧急前沿。**卫生经济学概念建模**：Agent 编排思维链 + 自洽 + 图谱 RAG，在乳腺癌（数据富）和 ATTR-PN（数据稀）上生成概念模型，HE 建模师和临床专家复核。证明可行性，不是替代建模师。
- **单篇小结**：院内眼科 Agent 若只加一层拒答，不够——要测「越狱之后校准/引用/弃权是不是一起塌」。经济学 Agent 可对 ROP/糖网铺设 CEA，但必须人签发状态转移和效用。两条都不是眼科诊疗。

### 12. VentiProtect ARDS 与基层分诊 scoping：5 分钟 vibe coding vs 还没有患者终点

- **日期 / 来源**：2026-10-16 / 2026-10-12；*Anaesth Crit Care Pain Med* / *Int J Med Inform*
- **链接**：https://doi.org/10.1016/j.accpm.2026.101934（PMID 42887688）· https://doi.org/10.1016/j.ijmedinf.2026.106769（PMID 42874138）
- **相关度**：工作流对照（医师 prompt 工程出床旁工具；基层 AI 分诊证据仍不成熟）
- **摘要**：**VentiProtect**：单名医师在 Antigravity + Claude Opus 4.6 上用八块结构化提示，4 分 25 秒生成呼吸机滴定助手（预测体重、潮气量、驱动压、顺应性、机械功率、氧合指数，带颜色警报和纠正建议）。公式用独立计算器核对。作者把它写成医师 prompt 工程能力的概念验证，而不是厂商交付物。**基层分诊 scoping**（检索至 2026-03-14）：17 项、12 国。14/17 是医师面对决策支持，3 项有患者端，**没有自主分诊**。诊断/筛查分诊最多（7），其次优先排序和转诊路由（各 4）。作为助手可抬眼底准确率 82.8%→91.1%、皮肤镜处理灵敏度 72.9%→94.2%；独立模型有时低于医师。准确率 41.2–98.3%，AUROC 0.65–0.90。11/17 仅内部验证；**没有前瞻随机，没有患者终点**。
- **单篇小结**：9 月「眼科医师 vibe coding」本周有了危重症对照——**会做床旁计算器 ≠ 已经是临床 Agent。** 基层综述则提醒：眼底准确率被 AI 抬高，证据仍停在回顾。接到青光眼/糖网分诊时，VentiProtect 只许当「公式必须本地算」的教具；分诊 scoping 禁止把 91% 写成已经能替全科分诊。

### 13. 同窗口其他可迁移医学 Agent（简记）

- **日期 / 来源**：2026-10-01 / 09-30 / 09-27 / 10-15；协议或方法卡
- **链接**：https://doi.org/10.3389/fmed.2026.1906806（PMID 42889141）· https://doi.org/10.3389/fdgth.2026.1915858（PMID 42877039）· https://doi.org/10.3390/s26196120（PMID 42884320）· https://doi.org/10.1002/kjm2.70304（PMID 42881559）
- **相关度**：方法可迁移（农村减药 AI Agent 可行性协议；人畜共患多 Agent 监测；步态证据选择安全总督；正畸「医师感知」Agent）
- **摘要**：**减药协议**（浙江 11 区）：30 名农村医师、≥150 名老年高血压+糖尿病多重用药，AI Agent 辅助减药，6 个月，评可行性/可接受/适宜性——还没有结果。**TransmiRisk-AI**：摄取/风险评估/警报/执行/日志/编排多 Agent + 混合风险分，Nipah / CCHF 案例。**EARL**：五个角色批评者打分，**确定性安全总督独占执行权**；在预记录步态上顺序披露特征包（不是新采集），64 人、3,520 次可重放。**正畸拥挤**：从 2D/3D 学到「医师感知」Agent；495 弓 PointNet++ *R*² 0.718、MAE 1.54 mm；有界 Gemini Agent 把 MAE 从 1.951 降到 1.437，错误信息则会变差。
- **单篇小结**：可搬的是 EARL 的「批评者可以说话，总督才能执行」——接到 MedRSI 工具注册或 OphthaAgent 写诊断时，应禁止推理模型自己改稳定工具表。减药条只是协议；人畜共患和正畸不是眼科。JAMA（10/15，PMID 42879271）OpenEvidence 2.5 年 2.71 亿查询证明临床信息平台已被大规模使用，但那是检索问答，不是诊疗 Agent，不展开。
