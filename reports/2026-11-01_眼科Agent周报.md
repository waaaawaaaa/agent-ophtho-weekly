### 1. Beyond Billing Codes: An Agentic Large Language Model Pipeline for Extracting Glaucoma Procedural Data from Free-Text Clinical Notes

- **日期 / 来源**：medRxiv 上线 **2026-10-30**（稿号 2026.10.29.26366154）；EuropePMC `PPR1354129`（首索引 10/31）。Bascom Palmer（Janet Kang / Nicholas Solages / Gustavo Samico / Naomi Gutkind / Rafael Scherer / Felipe A. Medeiros / Swarup S. Swaminathan）
- **链接**：https://doi.org/10.64898/2026.10.29.26366154 · https://www.medrxiv.org/content/10.64898/2026.10.29.26366154v1 · EuropePMC：https://europepmc.org/article/PPR/PPR1354129
- **相关度**：**直接相关（本周主条目）**——青光眼病历上的三阶段 Agentic 手术史抽取；不是阅片 Agent
- **摘要**：评估 HIPAA 合规容器里的 LLM Agentic 工作流，能否从青光眼自由文本抽出操作数据。对象是 Bascom Palmer Ophthalmic Repository 1,250 例（2014–2024），两名青光眼专科标注、必要时第三人仲裁：既往青光眼相关操作（名称、日期、细节）与拟行操作（名称、细节）。按 10% / 10% / 80% 划分。五模型——Claude Opus 4.6、DeepSeek-V4 Pro、GPT-5.5、Grok 4.1、Qwen3.6-35B-A3B——走 Microsoft Foundry 的 HIPAA 容器。流水线仍是三步 Agentic（抽取、校验、条件改写）再文本标准化。检测报准确率 / 灵敏度 / 特异度 / 精确度 / F1；阳性例报精确匹配与 Jaccard。另把既往操作标签对照 EHR 里的青光眼相关 CPT。测试集 1,984 条眼级标签（992 份病历 × 2 眼）：既往操作 1,057 眼（53.3%），拟行操作 152 眼（7.7%）。检测准确率：既往 0.965（Grok）–**0.996（Claude）**，拟行 0.969（DeepSeek / Qwen）–**0.978（Claude）**。阳性例精确匹配：既往 0.681–**0.890**，拟行 0.704–**0.849**；Jaccard 0.827–0.956 / 0.734–0.883。仲裁出的 1,760 条既往操作，CPT 只覆盖 **441（25.1%）**。作者把缺口归为外院手术和 CPT 颗粒度不够，并认为这条流水线可规模化刻画青光眼手术负担。
- **单篇小结**：这是对上周 GLLaucoMed「当前用药 / 拟变更分槽」的手术史姊妹篇——**同一仓库、同一三阶段、同一 Claude 领先**。可搬的不是 0.996，而是三张表：计费码不得当金标准（只抓住四分之一）；拟行操作阳性太稀，精确匹配会掉；标准化必须在院内容器做完，而不是推理时打外网。接到抗青光眼 / 抗 VEGF 队列筛选时，应禁止用「有没有小梁切除 CPT」替代自由文本抽取。不要把「Agentic」写成已经会排手术——它抽的是已经写在病历里的操作。预印本未经同行评议；GitHub `llmnotes` 最近推送仍为 **2026-07-27**，本窗口无新 commit。

### 2. OpenEvidence versus Six Leading Large Language Models in Refractive Surgery: Does Curated Medical Evidence Confer an Advantage?

- **日期 / 来源**：2026-10-26；*Journal of Cataract & Refractive Surgery*
- **链接**：https://doi.org/10.1097/j.jcrs.0000000000002088 · https://pubmed.ncbi.nlm.nih.gov/42929207/
- **相关度**：眼科相邻（屈光 BCSC 选择题；**不是** Agent）
- **摘要**：225 道 AAO BCSC 屈光手术选择题，对照 OpenEvidence 与六家通才（ChatGPT-4o、ChatGPT-5、Claude、Copilot、Gemini、Grok），并以 1,983 名 BCSC Self-Assessment 用户均分作基准。OpenEvidence 准确率最低（**76%**），显著低于全部六家通才（*P*<0.05）。Claude **92%**，Grok 89.8%，ChatGPT-5 / Copilot / Gemini 各 88%，ChatGPT-4o 86.2%。所有模型 95% CI 下限都过 60% 及格线。学员均分 77%。六家通才显著高于学员，OpenEvidence 没有。作者强调：差异不能完全用「没按规定格式作答」解释，也**不能**外推成开放临床场景已经全面落后。
- **单篇小结**：位置正好接在 10/15 *JAMA* OpenEvidence 用量文之后——**眼科医师几乎不用通用问答（use ratio 0.23），用了也不一定比通才更会做专科选择题。** 接到院内「买证据检索就能替代专科 Agent」的采购话术时，应要求：同一题库、同一作答格式、以及和学员均分对照。本条不是工具 Agent，不替代条目 1。

### 3. A clinical multimodal vision language foundation model with fine-grain explainability（EVLF-FM）

- **日期 / 来源**：2026-10-29；*Nature Medicine*。新加坡眼研 / Duke-NUS / A*STAR（Yang Bai / Haoran Cheng / Yang Zhou / **Daniel Shu Wei Ting** 等）
- **链接**：https://doi.org/10.1038/s41591-026-04655-5 · https://pubmed.ncbi.nlm.nih.gov/42957777/
- **相关度**：眼科相邻（六科多模态 VLM，**含眼科**；像素级接地 + 可解释，**不是**诊疗 Agent）
- **摘要**：现有医学基础模型多半单模态、推理不透明。EVLF-FM 用超过 130 万样本、18 个全球数据集、10 种影像、六科（皮肤 / 肝病 / **眼科** / 病理 / 呼吸 / 放射）做开发，再用 13,443 例外集、17 个数据集做外验。任务覆盖诊断、VQA 和像素级视觉接地。内验诊断均准确率 **0.895**，超过通才与专科对照；九模态视觉接地 Acc@0.5 **0.842**。外验称零样本 / 少样本 F1 仍有竞争力，模型更小。监督 + 视觉强化学习微调让解释对齐视觉证据；S.C.O.R.E. 人评均分 4.25/5。作者写明：还要更多场景验证，前瞻安全与效用试验之前不得常规部署。Ting 持有视网膜病 DL 专利及 EyRIS / aISIGHT 股权。
- **单篇小结**：这是对上周 JAMA OCTCases「通才仍在答题」的专科 VLM 对照——**会指回像素，仍不会调工具。** 接到 OphthaAgent / 黄斑裂孔报告槽时应抄：接地框必须可点回，禁止端到端一次出「CNV 活动」。不要把 0.895 均准确率写成已经覆盖青光眼/黄斑裂孔路径——那是六科内验平均。不是 Agent，不计入本周翻转。

### 7. An agentic AI system enhances clinical detection of immune-related adverse events in a multi-phase validation study

- **日期 / 来源**：2026-10-29；*Nature Cancer*。Dana-Farber / Harvard（Jack Gallifant / Danielle S. Bitterman 等）
- **链接**：https://doi.org/10.1038/s43018-026-01264-6 · https://pubmed.ncbi.nlm.nih.gov/42957896/
- **相关度**：**方法可迁移（本周正刊主对照）**——病历抽取 Agent + 人核 + 静默部署 + 交叉试验；可对青光眼手术史 / 用药槽
- **摘要**：免疫相关不良事件影响至多 40% 接受免疫检查点抑制剂的患者，识别仍靠费力且不一致的人工读病历。作者做成 Agentic LLM，从病历抽六类 irAE 的有无、时间、分级、归因和确定性。回顾：当前事件检测宏平均 F1 **0.92**，多类分级 0.66；自洽再抬 F1 0.14；最优配置约 **$0.02 / 份病历**。前瞻静默部署 3 个月，二元 F1 **0.72–0.79**。临床试验人员随机交叉：Agent 辅助少花 **2.71 分钟**（*P*<0.001），完整匹配 OR **1.45**（1.01–2.08；*P*=0.045），评分者一致从 Krippendorff α 0.22–0.51 升到 0.82–0.85。
- **单篇小结**：这是给条目 1 的外检课——**回顾 0.92 不等于静默部署还是 0.92**。复现青光眼手术史 / GLLaucoMed 时应同时报：回顾 F1、静默部署 F1、以及人核之后省了多少分钟。人核把一致率从「几乎随机」拉到 0.82，说明 Agent 的产品形态是副驾驶不是签发。不是眼科，irAE 也不是青光眼终点。

- **链接**：https://doi.org/10.1038/s41398-026-04335-5（PMID 42946723）· https://doi.org/10.7759/cureus.117090（PMID 42953439）· https://doi.org/10.1056/AIp2600239（PMID 42932715）

- **摘要**：**精神科概念验证**：Questioner / Evaluator / Navigator / Diagnoser 四 Agent 做协议化访谈和模块级筛查，带有界澄清和红旗升级。**影像监管**（*Cureus*）：从「单一预期用途的器械」走到会规划、调工具、触发下游动作的 agentic 工作流，提出数据–模型–编排–临床使用–机构生命周期五层问责。**NEJM AI 短评**（电子出版 8 月，本窗口索引）：agentic 队友会降低个体临床科学家的门槛，同时放大谁能把想法做成可靠研究的机构差距。

### 10. GPT-6.1 Terra、Gemini 4 Carbon 与 Mistral Large 4 开权：本周是「便宜计算机使用」和「还不能给开发者的旗舰」

- **日期 / 来源**：OpenAI / Google / Mistral 官方 **2026-10-26～10-29**
- **链接**：https://openai.com/index/introducing-gpt-6-1-terra · https://developers.openai.com/api/docs/models/gpt-6.1-terra · https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/ · https://deepmind.google/models/gemini/ · https://mistral.ai/news/mistral-large-4-oss/
- **相关度**：运行时（本周平台层增量；Duet / Skills 捐赠 / Argon GA / Decisions API 不重复）
- **摘要**：**GPT-6.1 Terra**（10/26）：API 名 `gpt-6.1-terra`，进 ChatGPT **Work / Codex** 和 API，**不进 Chat**。官方定位视觉推理、精确计算机使用和更自然的写作。标准价 **$1 / $5**（cached input $0.05），称比 GPT-5.6 Terra 和 GPT-6.1 Sol **便宜 50%**。上下文约 **1.05M**，知识截止 2026-06-01。官方：Agents’ Last Exam 中等努力比 5.6 Terra 高 15 个百分点、成本约三分之一，并与 GPT-6 Astra 打平且只要其约 1/10 单价；max 努力完成任务快三倍以上。内部易错提示：低努力错误率 53.6%→**16.7%**，max **4.3%**。Terminal-Bench 4.0 max **50.3%**（5.6 Terra 发布分 21.5%）。复杂编码仍建议 Sol / Astra。不支持阿联酋推理驻留。**Gemini 4 Carbon**（10/28）：官方「最强 Gemini 4」，长程 agentic + 网络安全。Artificial Analysis Intelligence Index v5.0 **59**（Argon 50，Astra 57，Opus 5.5 58）。DeepMind 对照表：Terminal-Bench 4.0 **65.2%**、Agents’ Last Exam v1.1 **77.4%**、OSWorld-2.1 离线 **81.5%**、AutomationBench **53.9%**、GraphWalks 256k–1M **96.2%**、SEC-bench Pro **88.2%** / ExploitGym **54.8%** / CWE-bench **71.0%**。介绍价与 Argon 相同 **$2 / $10**（cache 95% off），到期后 $4 / $20。**本周只给部分可信网络防御者和 Fairwind，不对开发者/企业/消费者开放**。**Mistral Large 4（Le Chonk）开权**（10/29）：1T 总参、约 49B 激活的多模态 MoE，1M 窗；API **$0.70 / $2.10**。Hugging Face 放 FP8 / NVFP4。官方称开权里 Coding Agent Index 领先；第三方表 Terminal-Bench 4 **28.3%**。许可是改过的 MIT：自托管可商用，**做模型即服务必须另签**。
- **单篇小结**：眼科科研 Agent 本周不缺新旗舰，缺的是**能进院内、价签清楚、计算机使用过关的小模型**。Terra 适合点设备报告、填表、看技术图，不得默认进 HIS；诊断规划仍留 Sol / Opus / 已开放的 Argon。Carbon 本周写进清单的唯一合法句子是「Fairwind 白名单，开发者还不能调」——不要把 59 分 AA Index 写成已经可跑 GUIDE。Large 4 开权适合本地抽表/红队，1T 权重不是门诊 GPU 能随便起的。独立三方尚未在眼底/OCT 轨迹上重跑 Terra vs Carbon vs Large 4。
