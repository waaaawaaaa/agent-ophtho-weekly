### 1. GUIDE: Computationally Augmented Consensus for Trustworthy Clinical Practice Guidelines

- **日期 / 来源**：arXiv 提交 **2026-10-12**；`cs.AI` / `cs.MA`。中山大学中山眼科中心（Yuanfan Lin / Jie Di / Xujin He / Zhenzhe Lin / Wenben Chen / **Haotian Lin**）
- **链接**：https://arxiv.org/abs/2610.16108 · https://doi.org/10.48550/arXiv.2610.16108
- **相关度**：**直接相关（本周主条目）**——多 Agent 副驾驶，主评测是 12 套 **NICE 眼科**指南；前瞻验证是白内障 IOL 选择
- **摘要**：指南更新被证据膨胀和专家共识拖住。GUIDE 把高通量、规则化步骤交给专用 Agent（问题分解、检索策略、文摘/全文筛选、数据抽取、GRADE、EtR 草稿），把 PICO 核定、偏倚风险和终稿共识留给专家；另设 reviewer Agent 在检索量打架、筛选不一致、抽取不一致时触发人干预，assistant Agent 把自然语言改成可执行检索式。12 套 NICE 眼科数据集（模块化、用原 NICE 材料隔开误差传播）：检索 / 文摘筛选 / 全文筛选召回 98.81% / 93.57% / **88.85%**，全文筛选精确度 84.60%；抽取准确率 98.02%（残留 1.98% 全是**数值漏提**，reviewer 只抓不一致、不抓遗漏）；GRADE 终确定性 86.06%；Delphi 式推荐与原文一致 **91.67%**。每套 162.17 分钟，Agent 115.66（71.32%）、人 46.51（28.68%）。去掉专家/reviewer 后，判断密集型步骤（尤其 RoB）掉点。另 20 套跨科数据全文筛选召回 88.83%。知识截止后 6 套时间外推上，终稿方向与 NICE 一致 100%。前瞻：更新 NICE 2017 白内障「术后同时看远近」的 IOL 选择，纳入 EDOF；GUIDE 辅助稿均分 3.73、同意 66.7%，纯人 3.87 / 73.3%，原 2017 稿 1.53 / 13.3%；GUIDE vs 纯人 *P*=0.588。局限：卫生经济学仍人手；RoB / 终推荐对 LLM 推理敏感；触发规则是静态的。
- **单篇小结**：这是对上周 OphthaAgent「工具可错」和 9/28 MedRSI「慢注册」的第三种眼科写法——**对象从眼底图换成证据体**。可搬的不是 91.67% 这个绝对分，而是三张表：双检索/双筛选/双抽取 + reviewer 只在不一致时叫人；数值漏提必须单独告警（本系统没抓到）；终稿不得无人签发。接到 GAO-Triage / KGR-MAS / AI-TEC 时，应把 AAO / NICE / 抗 VEGF 指南更新写成「副驾驶车间」，而不是让通才一次生成推荐。不要把 GUIDE 写成已经替代指南委员会，更不要和 OphthaAgent（眼底工具）或 OphthaReason（看图推理）混名。

### 2. Artificial intelligence-supported diabetic retinopathy screening in Tanzania: a randomised controlled trial

- **日期 / 来源**：2026-10-12；*The Lancet Global Health*。LSHTM / Kilimanjaro Christian Medical Centre / Moorfields–UCL（Pearse A. Keane / Alastair Denniston）
- **链接**：https://doi.org/10.1016/j.langlo.2026.104062 · https://pubmed.ncbi.nlm.nih.gov/42863478/
- **相关度**：眼科相邻（本周最重的临床终点；**不是** LLM Agent，但是筛查 Agent 必须抄的到诊 RCT）
- **摘要**：非洲糖网筛查的主要失败不在检出，而在转诊后不到诊。24 家医院 NCD/糖尿病门诊、个体 1:1 随机。AI 组：现场出非需转诊 / 需转诊 / 不可分级，并当面咨询，需转诊或不可分级直接转中心眼科；对照组：数周后人工阅片 + 电话咨询。入组 2,378（AI 1,192 / 对照 1,186）；掩蔽的英国认证阅片员判定真需转诊 904 人（437 / 467）。主终点：真需转诊者 8 周内到中心眼科——AI **157/437（35.9%）** vs 对照 **85/467（18.2%）**，绝对差 17.7 个百分点（95% CI 12.0–23.4；OR 2.52，1.86–3.42；*P*<0.0001）。ISRCTN18317152，已完成。
- **单篇小结**：上周利比里亚离线相机报的是 11 例需转诊的灵敏度区间；本条把问题改成 **到了没有**。接到糖网/青光眼筛查 Agent 时应把 8 周到诊、而不是现场 AUROC，写成主栏。35.9% 仍然低，AI 只是把漏到诊砍了一半，不是已经建成闭环。Keane 组利益披露按原文脚注引用。

### 3. EyeGraph: A Multi-granularity Medical Vision-Language Foundation Model with Knowledge Graph Reasoning for Ophthalmic Interpretation

- **链接**：https://doi.org/10.1109/TMI.2026.3742614 · https://pubmed.ncbi.nlm.nih.gov/42867984/ · 代码：https://github.com/ZardCAI/EyeGraph
- **相关度**：眼科相邻（眼科 VLM + 图谱推理；**不是**工具编排或诊疗 Agent）
- **摘要**：眼科 VLM 缺大规模图文对，且幻觉在临床上不可接受。作者发 **IT-Retinal** 多粒度眼科 VQA 数据集，再训 EyeGraph：定向预训练 + 微调，推理时把 Graph of Thought 与 Think on Graph 合成 G2T，用结构化外部知识约束输出。七项临床相关基准（诊断、结构检测/定位、报告生成）称 SOTA；G2T 抬报告事实一致性。代码与交互 demo 公开。

### 5. Evaluation and Comparison of Large Language Models in Answering Frequently Asked Patient Questions on Glaucoma

- **日期 / 来源**：2026-10-12；*Journal of Glaucoma*。UCLA + Wilmer（Pradeep Ramulu）
- **链接**：https://doi.org/10.1097/IJG.0000000000002794 · https://pubmed.ncbi.nlm.nih.gov/42868997/
- **相关度**：眼科患教 LLM（青光眼 FAQ；**非 Agent**）
- **摘要**：Google「People Also Ask」前 10 题，覆盖基础知识、治疗、生活方式、预后。ChatGPT-o1 vs DeepSeek-R1，两名青光眼专科 4 分信度（1=无需澄清，4=不合格）；对照同查询前两名网页。中位信度 2.3 vs 2.8（*P*=0.08），与网页 2.3 相当（*P*=0.18）。两模型都在基础知识和生活方式上失手：会虚构管状视野、给灌水/饮食/屏时等无依据建议。可读性 8–12 年级。

### 6. Grounded ophthalmic AI beyond the electronic health record trap: a critical narrative review

- **日期 / 来源**：2026-10-13；*BMJ Health & Care Informatics*
- **链接**：https://doi.org/10.1136/bmjhci-2026-102293 · https://pubmed.ncbi.nlm.nih.gov/42869617/
- **相关度**：眼科治理（把「硬渗出增加了」写成可审计三元组，而不是再训一个通才）
- **摘要**：EHR 已经证明信息化可以加重文书和倦怠；AI 会进到更深一层——写摘要、读图、建议随访。糖网筛查和病灶级 DL 在限定任务上成功，但临床解释不是分类：「黄斑硬渗出增加了」要求定位中心凹/黄斑、分割、纵向配准、变化定量和忠实语言。未解的信息学问题是**接地的临床解释**：图像 → 可被医师检查的 发现–部位–变化 三元组。主张三层：全球标准化客观观察、显式本地政策/工作流、医师编写并由安全门治理的 AI 操作。定制不应被卖成厂商私活，而应写进采购和生命周期监管。
- **单篇小结**：这是对上周耶路撒冷「算法先开口」和本周 FFA-SegGPT 的理论页。院内清单应要求输出可点回病灶，而不是一段不可追问的印象。不要把叙事综述写成新系统。

### 8. HierarchiRetina、跨设备 OCT 域适应与本窗口其他眼科工具卡

- **日期 / 来源**：arXiv / 期刊 **2026-10-12～10-16**
- **链接**：https://arxiv.org/abs/2610.17933 · https://arxiv.org/abs/2610.21719 · https://arxiv.org/abs/2610.20671 · https://arxiv.org/abs/2610.18824 · https://doi.org/10.1016/j.survophthal.2026.10.006（PMID 42887655）· https://doi.org/10.1007/s10278-026-02379-z（PMID 42875691）· https://doi.org/10.1016/j.xops.2026.101386（PMID 42860999）
- **相关度**：眼科相邻工具（级联筛查、跨设备、分割、全身风险；都**不是** Agent）
- **摘要**：**HierarchiRetina**（10/13）：筛查→异质 MoE 病灶分割→病变门控分级；六数据集 58,689 张 held-out，端到端二次加权 kappa 0.804，转诊灵敏度 0.832 / 特异度 0.947，**66% 错误来自筛查门**；消融显示分级甚至可以忽略分割掩膜。**跨设备 OCT 发育分类**（10/15，投 *Nature Medicine*）：无监督域适应，四设备、五中心，验证准确率 87.75%–96.06%。**LightHybridNet**（10/14）ODIR-5K 多标签加权 F1 91.51%。**RetinaSC**（10/13）把糖网分级写成语义通信，MobileNetV2 加权 F1 0.76–0.78、端到端 8.16 ms。*Survey of Ophthalmology*（10/16）综述脉络膜 AI。OCTA V2Vnet（10/14）在 OCTA-500 上 mDice 79.14%，抗运动伪影。AREDS **Dr Noon CVD**（本窗口 *Ophthalmol Sci*）：眼底 DL 估 10 年 ASCVD，可在缺实验室、PCE 算不出时仍给分层。
- **单篇小结**：级联系统必须报**误差从哪一层来**——HierarchiRetina 把 66% 记在筛查门，比再报一张 kappa 更有用。跨设备 OCT 域适应可接到儿童发育/青光眼 OCT 工具槽，但目标是正常 vs 异常发育，不是青光眼分期。全身 CV 风险与眼病诊断必须分栏（接上周 Visionary AI）。

### 9. Clinician Use of an Artificial Intelligence-Enabled Clinical Information Platform

- **日期 / 来源**：2026-10-15；*JAMA*。Harvard / OpenEvidence
- **链接**：https://doi.org/10.1001/jama.2026.21868 · https://pubmed.ncbi.nlm.nih.gov/42879271/
- **相关度**：眼科相邻 / 治理（OpenEvidence 真实使用；眼科相对人力的查询比仅 **0.23**）
- **摘要**：2024-01～2026-06，NPI 核实的 952,008 名临床人员提交 2.71 亿条查询；月活从 355 到 703,265。抽样 3,880 万条用 LLM 分类。查询用途：临床决策 51.9%（治疗管理 33.1%，诊断只占 13.9%）。相对全国人力，肿瘤血液 2.00、内科 1.88、全科 1.80；**眼科 0.23**、放射 0.24、骨科 0.24。住院医/Fellow 1.84，毕业十年内医师 2.54。跨专科提问从肿瘤血液 35% 到急诊 88%。
- **单篇小结**：眼科医师目前几乎不把通用临床问答 Agent 当主工具——这和「眼科专用工具 Agent」不是同一市场。院内若只采购 OpenEvidence 式问答，不要指望它覆盖眼底/OCT 轨迹。诊断只占 13.9%，治疗问题才是真实用量。作者与 OpenEvidence 有任职关系，引用时写利益。

### 10. Skill-guided agentic reasoning enables longitudinal synthesis of myeloma records at expert-level concordance

- **日期 / 来源**：2026-10-14；*npj Precision Oncology*。TUM / Oxford
- **链接**：https://doi.org/10.1038/s41698-026-01733-2 · https://pubmed.ncbi.nlm.nih.gov/42875467/
- **相关度**：**方法可迁移（本周正刊主对照）**——技能库引导的纵向病历 Agent；可对青光眼/nAMD 多年随访
- **摘要**：811 名骨髓瘤患者、25 年、44,962 份文书、1,334,677 条化验。对照：单次 RAG、迭代 RAG、迭代 RAG+同一技能库、全上下文。469 对专家裁定的患者–问题。技能引导 Agent 把一致率做到 **80.1%**，超过迭代 RAG 75.7% 和全上下文 75.8% 的天花板；最复杂任务 +11.2 个百分点。同一技能库交给迭代 RAG 总体到 79.0%，但最长病历最高十分位上 Agent 仍高 10.3 个百分点（*P*=0.017）。总错误率 12.2% 接近专家分歧 13.6%，**临床显著错误占比 57.8% vs 专家的 18.8%**。
- **单篇小结**：这是对上周 LongCAF「纵向记忆」的病历合成版。接到抗 VEGF / 青光眼多年随访时应抄：技能库、最长记录上的增量、以及临床显著错误必须单独报——总体一致率够了，不等于错的不致命。不要把 80.1% 写成已经可以无人签发入院。

### 11. Symptio / HEM-Med / PRISMATIC / MedPAO-VL / UMCR：问诊、用药记忆、处方冲突、胸片 Agent、概念链接

- **日期 / 来源**：期刊索引或 arXiv 提交 **2026-10-12～10-15**
- **链接**：https://doi.org/10.3389/fdgth.2026.1882397（PMID 42877149）· https://arxiv.org/abs/2610.20191 · https://arxiv.org/abs/2610.19762 · https://arxiv.org/abs/2610.21794 · https://arxiv.org/abs/2610.17363
- **相关度**：方法可迁移（多 Agent 问诊/用药/报告；都**不是**眼科）
- **摘要**：**Symptio**（*Front Digit Health*，本窗口可见）：把 SOCRATES / ROS / SAMPLE 写成可执行约束的多 Agent 预问诊；100 个模拟门诊，三框架全结构一致 87%，微平均 F1 98.79%；无高严重错误，但 58 处字段级差异（28 处中等），必须医师审。**HEM-Med**（10/14，BIBM）：多中心用药推荐的分层 agentic 记忆，把可迁移经验和医院残差拆开，并加相互作用/处方集安全解码。**PRISMATIC**（10/14）：黑板架构多专科 Agent 共写处方，DSWA 调长期权重、DFPC 消当前冲突；MIMIC-IV。**MedPAO-VL**（10/15，ECCV BISCUIT）：胸片 plan–act–observe 报告 Agent，专家评分准确 3.5/5、结构 4.3/5。**UMCR**（10/12）：任意本体上的医学概念识别，用指南约束 + agentic 链接，评 MedPath。
- **单篇小结**：上周体检多 Agent 证明拆 Agent 不自动更安全；本周补四句——问诊框架必须可审计、用药记忆必须分院、处方冲突必须上黑板、报告必须 plan–act–observe 而不是一次生成。眼科预问诊（GAO 电话、白内障 IOL 选择）可抄 Symptio 的框架约束；抗 VEGF 联合用药可抄 PRISMATIC 的冲突可见。全部不是眼病终点。

### 12. MedicalAgentsBench、卫生经济学 Graph-RAG Agent 与 *Patterns* 脚手架对照

- **日期 / 来源**：2026-10-09 / 10-12 正刊；本窗口可见
- **链接**：https://doi.org/10.1016/j.patter.2026.101610（PMID 42891289）· https://doi.org/10.1007/s41669-026-00687-2（PMID 42864590）
- **相关度**：方法可迁移（内化推理 vs 外显 Agent；人在环的卫生经济学概念化）
- **摘要**：**MedicalAgentsBench**：从八个医学集滤出 862 道复杂题。内化推理（DeepSeek-R1 / o1-mini / o3-mini）和外显多 LLM 脚手架各自独立涨分，**叠加最好**——o3-mini + MDAgents **35.1%**，且在成本–性能帕累托前沿。便宜模型做轻量优化是资源受限入口。**卫生经济学概念化**（*PharmacoEconomics Open*，10/12）：agentic Graph-RAG + 人在环，乳腺癌（富数据）和 ATTR-PN（罕见病）各出疾病概念图和状态转移图，经文献和建模师/临床医师核对。
- **单篇小结**：上周 MedicalHarness 说分数属于「模型 × harness」；本条说 **推理模型和 Agent 脚手架不是替代关系**。复现 GUIDE / nAMD 分析时，应同时报骨干是否带内化推理、以及脚手架名字。卫生经济学那篇提醒：GUIDE 自己也把成本效果留给人手——Agent 可以画状态图，不能签发报销模型。PMID 42891289 电子出版早于窗口，仅因本周索引列入。
